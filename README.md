## 🧠 O que Aprendi

### 📌 Fundamentos
- O que é um algoritmo e como pensar de forma lógica
- Tipos de dados: inteiro, real, caractere e lógico
- Declaração e uso de variáveis e constantes
- Entrada e saída de dados com `leia` e `escreva`

### 📌 Operadores
- Operadores aritméticos: `+`, `-`, `*`, `/`, `div`, `mod`
- Operadores relacionais: `>`, `<`, `>=`, `<=`, `=`, `<>`
- Operadores lógicos: `e`, `ou`, `nao`

### 📌 Estruturas de Decisão
- Estrutura `se/senao` para decisões simples e compostas
- Estrutura `escolha/caso` para múltiplas opções
- Aninhamento de condicionais

### 📌 Estruturas de Repetição
- `enquanto` — repete enquanto uma condição for verdadeira
- `repita/ate` — repete até uma condição ser verdadeira
- `para` — repete um número determinado de vezes
- Uso de contadores e acumuladores

### 📌 Modularização
- Criação e uso de **procedimentos**
- Criação e uso de **funções** com retorno de valores
- Passagem de parâmetros por valor e referência

### 📌 Estruturas de Dados
- **Vetores** — armazenamento de múltiplos valores em uma dimensão
- **Vetores paralelos** — relacionar dados de diferentes vetores pelo índice
- **Matrizes** — armazenamento em duas dimensões (linhas e colunas)
- Percorrer, buscar e manipular dados em vetores e matrizes

## ▶️ Como Executar os Arquivos

3. Abra o VisuAlg
4. Clique em **Arquivo → Abrir** e selecione o arquivo
5. Pressione **F9** para executar
